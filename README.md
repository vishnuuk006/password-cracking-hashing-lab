# Password Cracking and Hashing Lab

An educational cybersecurity project demonstrating password hashing,
salting, password verification, dictionary attacks, and brute-force
password cracking.

## Objective

The objective of this project is to understand how passwords are hashed,
how salting improves password protection, and how weak passwords can be
identified through controlled password-cracking techniques.

## Features

- MD5 hashing demonstration
- SHA-1 hashing demonstration
- SHA-256 hashing demonstration
- Random salt generation
- Salted password hashing
- Password verification
- Dictionary attack
- Brute-force attack
- Hashcat password auditing
- John the Ripper password auditing
- Basic analysis of cryptographic weaknesses

## Technologies and Tools

- Python 3
- Hashlib
- Hashcat
- John the Ripper
- Kali Linux
